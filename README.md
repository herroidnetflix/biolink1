# Navvora Telugu — GitHub Pages

Static premium Link-in-Bio site for Navvora Telugu.

## Deploy
1. Upload all files to a GitHub repository.
2. Put the supplied Navvora United TFI image at `assets/images/navvora-united-tfi.jpg`.
3. GitHub → Settings → Pages → Deploy from branch → `main` → `/root`.
4. Save and open the generated Pages URL.

No build step or Node.js is required.
